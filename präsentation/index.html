Willkommen

Worum geht es in meinem Projekt?

In meinem Projekt geht es um die Entwicklung einer Programmiersprache, die sehr simpel und einfach zu lernen ist.

Funktionsweise

1. Lexing

Beim Lexing wird der eingegebene Code in seine Einzelteile zerlegt.

*KI-generiertes Bild

2. Parsing

Der zweite Schritt ist das Parsing. Dabei werden die Tokens in einen abstrakten Syntaxbaum (AST) umgewandelt, der die logische Struktur des Codes darstellt.

*KI-generiertes Bild

3. Codegenerierung

Der dritte Schritt ist die Codegenerierung. Dabei wird der AST in ausführbaren Code umgewandelt.

*KI-generiertes Bild

Wo liegt der Unterschied zu komplexeren Sprachen?

Meine einfache Sprache:

drucke "Hello World"

Im Vergleich dazu Java:

public class HelloWorld {
    	public static void main(String[] args) {
        	System.out.println("Hello World");
    	}
	}
