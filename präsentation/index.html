SPL

Simple Programming Language

Die Logik des Programmierens einfach verstehen

Das Ziel

Entwicklung einer Programmiersprache, die Barrieren abbaut und den Fokus rein auf die logischen Strukturen legt.

Wie funktioniert SPL?

Drei Hauptschritte von der Eingabe bis zur Ausführung.

1. Lexing

Zerlegung des Quellcodes in Tokens (Sinn-Einheiten).

Hier erklärst du, wie Wörter wie 'drucke' erkannt werden.

2. Parsing

Erstellung eines Abstrakten Syntaxbaums (AST).

3. Codegenerierung

Umwandlung des AST in ausführbare Logik.

Warum SPL?

Ein Vergleich der Komplexität.

Vergleich: Ausgabe

Java:


                            public class HelloWorld {
                                public static void main(String[] args) {
                                    System.out.println("Hello World");
                                }
                            }

SPL:


                            drucke "Hello World"

Vergleich: Eingabe

Java:


                            import java.util.Scanner;
                            public class Main {
                                public static void main(String[] args) {                                        Scanner s = new Scanner(System.in);
                                    String name = s.nextLine();
                                    System.out.println("Hallo " + name);
                                }
                            }

SPL:


eingabe name
drucke "Hallo " + name

Vergleich: Rechnen

C++:


                            #include <iostream>
                            int main() {
                                int a = 10;
                                double b = 5.5;
                                std::cout << a + b;
                                return 0;
                            }

SPL:


                            a = 10
                            b = 5.5
                            drucke a + b
